# Split-Flap Hunger Counter

Compteur split-flap affichant une estimation des morts de la faim dans le monde.

## Données

- **9 millions** de décès par an estimés par l'OMS (malnutrition et maladies associées)
- Proportionnel au temps écoulé dans l'année courante
- Mise à jour toutes les 3 secondes

## Stack

- HotFX `<hotfx-split-flap>` web component
- Web Audio API (sons mécaniques inline base64)
- Vanilla JS, CSS custom properties
- Déployé sur [here.now](https://here.now)
